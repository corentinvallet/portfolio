    ☁️ Cloudinary
    📖 Guide de configuration
    Créez un compte gratuit sur cloudinary.com. Le plan gratuit offre 25 GB.
    Dans le tableau de bord, notez votre Cloud Name (ex: dxyz1234).
    Allez dans Settings → Upload → Upload presets, cliquez "Add upload preset".
    Nommez-le terraloc_unsigned, passez Signing Mode sur "Unsigned", sauvegardez.
    Renseignez votre Cloud Name et le preset ci-dessus, puis cliquez Enregistrer.
