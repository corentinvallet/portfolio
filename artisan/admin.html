Configuration Cloudinary

Cloudinary est un service cloud gratuit pour héberger et optimiser vos images. Créez un compte sur cloudinary.com, puis renseignez vos identifiants ci-dessous.

Visible dans votre dashboard Cloudinary
Settings → Upload → Upload presets (mode unsigned)
Dossier de destination dans votre médiathèque Cloudinary
Guide de démarrage rapide
  1. Créer un compte gratuit sur cloudinary.com
  2. Copier votre Cloud Name depuis la page d'accueil du dashboard
  3. Aller dans Settings → Upload → Upload presets → Ajouter un preset en mode Unsigned
  4. Copier le nom du preset et le coller ci-dessus
  5. Sauvegarder et tester la connexion
