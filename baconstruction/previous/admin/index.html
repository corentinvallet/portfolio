🚀 Guide de démarrage rapide

  1. Rendez-vous dans Cloudinary pour configurer vos identifiants d'upload.
  2. Allez dans Galerie photos pour ajouter, éditer ou supprimer des photos.
  3. Modifiez les textes dans chaque section (Héro, Services, À propos…).
  4. Cliquez sur Enregistrer pour exporter la configuration JSON.
  5. Intégrez le JSON exporté dans votre site via le script de chargement.

📖 Comment configurer Cloudinary

  1. Créez un compte gratuit sur cloudinary.com
  2. Dans le Dashboard, copiez votre Cloud Name
  3. Allez dans Settings → Upload
  4. Sous "Upload presets", cliquez Add upload preset
  5. Choisissez Signing Mode : Unsigned
  6. Notez le nom du preset et collez-le ci-dessus
  7. Dans "Folder", entrez ba_construction (ou votre dossier)
  8. Sauvegardez et testez la connexion ✓
