Paramètres → Upload → Upload Presets
Comment obtenir les clés Cloudinary
  1. Créez un compte gratuit sur cloudinary.com
  2. Copiez le Cloud Name affiché sur votre tableau de bord
  3. Allez dans Settings → Upload → Upload Presets
  4. Créez un preset en mode Unsigned
  5. Copiez son nom dans le champ Upload Preset ci-dessus
